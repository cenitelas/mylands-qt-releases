# NeuroForgeQt — сборки

Готовые сборки бота для My Lands под macOS, Windows и Linux — во вкладке **Releases**.

Бот обновляется сам: раз в час проверяет этот репозиторий и ставит новую версию.
Ваши настройки и игровая сессия лежат в папке `data` рядом с программой и при обновлении не трогаются.

Чтобы завести второго бота (другой аккаунт) — скопируйте программу в другую папку **без папки data**.
