# NeuroForgeQt — сборки

Готовые сборки бота для My Lands под macOS, Windows и Linux — во вкладке **Releases**.

Бот обновляется сам: раз в час проверяет этот репозиторий и ставит новую версию.
Проверить вручную: «Настройки» → «Обновление» → «Проверить обновление».
Ваши настройки и игровая сессия лежат в папке `data` рядом с программой и при обновлении не трогаются.

Чтобы завести второго бота (другой аккаунт) — скопируйте программу в другую папку **без папки data**.

## Первый запуск

**Windows — «Windows защитил ваш компьютер» / «подозрительное приложение».**
У программы нет платной цифровой подписи, поэтому SmartScreen предупреждает о любой новой версии,
скачанной браузером. Это не вирус. Варианты:

- до распаковки: правой кнопкой по zip → «Свойства» → галка **«Разблокировать»** → «ОК», потом распаковать;
- или при запуске: **«Подробнее»** → **«Выполнить в любом случае»**.

Нужно один раз: обновления бот скачивает сам, и на них предупреждение не появляется.

**macOS** — при первом запуске: правой кнопкой по `NeuroForgeQt.app` → «Открыть» → «Открыть».
На macOS 15 и новее: запустите один раз, затем «Системные настройки» → «Конфиденциальность и безопасность» →
«Всё равно открыть».

**Linux** — распакуйте архив и запустите `NeuroForgeQt.AppImage` (если не запускается: `chmod +x NeuroForgeQt.AppImage`).
